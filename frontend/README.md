# Для запуска Frontend приложения

1. Создать .env файл в корне проекта
2. В созданный файл вставить содержимое .env.example 
3. Вставить в терминал код ниже
   (Node >= 17 (Стабильно работает v18.18.2))

```
npm install
npm run dev
```
## Приложение работает на 3000 порту, но можно при желании поменять в файле .env
